# Social Shortcuts

## 1.0.0

- Names in the Communities chat window now take the shortcuts too.
- Raid frames keep the shortcuts when another addon changes how they are set up.
- A shortcut used where the game hides player names shows a red notice instead of doing nothing.
- Invite in the Group Finder follows the game's own Invite button and shows a notice on listings it can't invite.
- Add Friend defaults to Shift on Windows instead of the Windows key, which opened the Start menu.
- The first load prints one line naming your keys and `/ssc`.
- The addon menu tooltip lists your current keys.
- `/ssc` in combat opens the settings once combat ends.
- Settings use the game's own names: Whisper, Invite, Add Friend and None.
- Add Friend on a Battle.net friend no longer adds their current character.
